xhdfe (py_hdfe_v11) help

Version: 2.21.0.20260725 (25jul2026)

Python bindings for the v11 C++ HDFE estimator. Defaults mirror reghdfe-style behavior: singleton dropping, fixed-effect DoF adjustments, and robust/cluster inference options.

The v11 notebook uses these environment variables (they override the defaults below):

  • HDFE_V11_TOL_NLSWORK, HDFE_V11_MAX_ITER_NLSWORK
  • HDFE_V11_TOL_PANEL, HDFE_V11_MAX_ITER_PANEL

The notebook expects py_hdfe_v11 to be built into build/ at the repo root (or ../build/ when executed from notebook/). If you use a versioned build directory (e.g., build_cpp_v11), adjust the path accordingly.

Constructor options

  • se_type (default "unadjusted"): covariance estimator. Accepted values:
    • Homoskedastic: "unadjusted", "homoskedastic", "classical", "unadj", "ols"
    • Robust: "robust", "hc1", "heteroskedastic"
    • Cluster: "cluster", "clustered" (requires clusters in fit)
  • tol (default 1e-8): convergence tolerance for the FE absorber.
  • max_iter (default 150): max absorption iterations.
  • check_interval (default 1): check convergence every k absorption iterations.
  • fit_intercept (default True): append intercept to X. With absorbed FEs and no IV, the intercept is computed after absorption and its inference entries are NaN.
  • num_threads (default 0): if > 0, force that many threads. If 0, auto-threading is used.
  • default_threads (default 0): base thread count for auto-threading (0 = OpenMP max / hardware).
  • max_threads (default 0): cap for auto-threading (0 = no cap).
  • min_parallel_rows (default 20000): below this, auto-threading runs single-threaded.
  • target_rows_per_thread (default 500000): auto-thread heuristic for row-to-thread ratio.
  • drop_singletons (default True): drop singleton observations before estimation.
  • keepsingletons (default None): if supplied, overrides drop_singletons (reghdfe compatible). Keeping singletons can bias inference in clustered designs; see http://scorreia.com/reghdfe/nested_within_cluster.pdf.
  • retain_fes (default False): recover FE contributions after estimation. When feasible, cached alphas are accumulated during absorption to avoid a second recovery pass; otherwise a store-alphas MAP recovery is used (not allowed with group/individual mode).
  • symmetric_sweep (default False): enable symmetric sweeps in the absorber and auto-method logic.
  • absorption_method (default "auto"): "auto", "gauss-seidel"/"gauss_seidel"/"gs", "symmetric"/"sym"/"symgs"/"symmetric_gauss_seidel", or "jacobi".
  • jacobi_relaxation (default 0.0): relaxation parameter for Jacobi; <= 0 uses the default 2/(J+1) rule.
  • level (default 95.0): confidence interval level (percent). If in (0, 1], treated as a fraction.
  • dofadjustments (default None): reghdfe-style DoF adjustments. Accepts a string or list of: all, none, firstpair, pairwise, clusters, continuous. When provided, only the listed tokens are enabled (like Stata).
  • groupvar (default None): when truthy, compute the first mobility group and store in groupvar_ (requires dofadjustments not set to none and at least two FEs).
  • ssc_k_adj (default None): fixest-style K adjustment (N-1)/(N-K).
  • ssc_k_fixef (default None): how to count FE DoF in K ("full", "none", "nonnested").
  • ssc_k_exact (default None): use exact FE rank for K (df_a_exact) instead of level counts.
  • ssc_g_adj (default None): fixest-style G adjustment for clustered SEs G/(G-1).
  • ssc_g_df (default None): multiway cluster df rule ("min" or "conventional").
  • ssc_t_df (default None): override t degrees of freedom (<= 0 disables override).

When ssc_* arguments are left as None, the defaults are K.adj=True, K.fixef="full", K.exact=True, G.adj=True, G.df="min", and t.df disabled.

Module enums

  • StandardErrorType: homoskedastic, robust, cluster.
  • AbsorptionMethod: auto, gauss_seidel, symmetric_gauss_seidel, jacobi.

Threading behavior

Auto-threading is enabled when num_threads == 0 and OpenMP is available:

  • If n_rows < min_parallel_rows, use 1 thread.
  • Else use default_threads (or OpenMP max / hardware concurrency if 0).
  • Clamp by target_rows_per_thread and max_threads.

If OpenMP is not enabled, the estimator runs single-threaded unless num_threads > 0.

GPU backend selection

GPU acceleration targets only the fixed-effect absorber. The CPU estimator remains the canonical path for all other computations.

Build-time options (CMake):

  • -DXHDFE_ENABLE_CUDA=ON to compile the CUDA backend.
  • -DXHDFE_ENABLE_METAL=ON to compile the Metal backend (macOS only).
  • -DXHDFE_GPU_BACKEND_DEFAULT=cuda|metal|cpu to change the compiled default.

Runtime override:

  • XHDFE_GPU_BACKEND=cpu|cuda|metal forces the backend selection.
  • If the requested backend is unavailable (not compiled, or no GPU), the code falls back to CPU.

Runtime environment variables

These optional environment variables control caching, diagnostics, and advanced backend behavior:

  • XHDFE_MOBILITY_PROFILE: path to a mobility profile file; enables reuse when signatures match.
  • XHDFE_MOBILITY_MODE: off, auto, read, or write.
  • XHDFE_ABSORPTION_CACHE: path to an absorption cache file (transformed y/X).
  • XHDFE_ABSORPTION_CACHE_MODE: off, auto, read, or write.
  • XHDFE_FE_STRUCTURE_CACHE: path to a fixed-effect structure cache (FE ids + singleton filters).
  • XHDFE_FE_STRUCTURE_MODE: off, auto, read, or write.
  • XHDFE_FE_DIAG_FILE: append fixed-effect diagnostics to the given text file.
  • XHDFE_USE_KRYLOV: set to 1 to allow Krylov-based absorption when available.
  • XHDFE_DEBUG_SOLVER: set to 1 to emit solver debug logs.

Cache and profile files are only reused when data signatures match exactly; otherwise they are ignored.

Fit arguments

fit(y, X, fes=None, weights=None, clusters=None, instruments=None, endogenous_idx=[], group=None, individual=None, aggregation="mean")

  • y: 1-D array of length n.
  • X: 2-D array (n x p).
  • fes: sequence of 1-D integer arrays (each length n). Empty or None means no fixed effects.
  • weights: optional 1-D array (length n); must sum to a positive value.
  • clusters: optional cluster IDs. Accepted forms:
    • 1-D array (length n) for one-way clustering
    • 2-D array (n x q) for q-way clustering
    • sequence of 1-D arrays (each length n)
  • instruments: optional 2-D array (n x q), required for IV/2SLS.
  • endogenous_idx: 0-based column indices in X (slope columns only; intercept is never indexed).
  • group: optional 1-D array (length n). When set, data are collapsed by group and a grouped estimator is used.
  • individual: optional 1-D array (length n). Requires group and that individual is also one of the FE arrays in fes. Enables group/individual absorber.
  • aggregation: "mean" (default; aliases "avg"/"average") or "sum" for group aggregation.

Group and individual mode

Setting group (and optionally individual) triggers a grouped workflow:

  • group without individual: collapses data to group level and runs standard FE absorption on the collapsed data.
  • group with individual: requires individual to be included in fes. This uses the group/individual absorber (reghdfe-style) and does not support retain_fes.
  • aggregation controls whether group-level variables are averaged or summed.
  • drop_singletons applies to group/individual structure (group singletons are removed).

IV / 2SLS support

Provide both instruments and endogenous_idx to run 2SLS. Errors are raised if one is provided without the other. IV is not available when group is specified (with or without individual).

Collinearity handling

After partialling-out, slope regressors with near-zero variation are omitted (relative tolerance 1e-9); additional rank-collinearity checks use max(1e-7, tol * 10). The output arrays are expanded back to the original column layout:

  • omitted slopes get coef = 0
  • inference entries (stderr, tvalues, pvalues, conf_int, covariance) are NaN

Collinearity handling applies to both OLS and IV; in IV, endogenous_idx is remapped to kept slope columns (and IV errors if nothing remains).

Output attributes

After fit, the regressor exposes:

  • summary() returns a formatted text table.
  • Estimates: coef_, stderr_, tvalues_, pvalues_, conf_int_, covariance_, residuals_.
  • Sample stats: nobs_, nobs_full_, num_singletons_, sample_index_ (0-based indices of kept rows; empty in grouped fits).
  • DoF stats: df_resid_, df_resid_unadj_, df_m_, df_a_, df_a_levels_, df_a_exact_, df_a_nested_.
  • DoF notes: df_a_ uses the exact FE rank (df_a_exact_) and does not follow ssc_k_*. df_resid_unadj_ = n - k - df_a_, while df_resid_ reflects SSC or ssc_t_df.
  • Fit stats: r2_, r2_within_, rss_, tss_, tss_within_, num_iterations_, converged_.
  • FE stats: fe_num_levels_, groupvar_ (1-based mobility group IDs, if enabled).
  • Cluster stats: num_clusters_, cluster_counts_, cluster_combo_counts_, cluster_scale_.
  • Runtime: threads_used_, absorption_method_used (AbsorptionMethod enum).

Fixed-effect recovery

Set retain_fes=True in the constructor to recover FE contributions:

  • fe_effects_: list of per-observation FE contributions (one vector per FE dimension).
  • fe_recovery_iterations_, fe_recovery_max_delta_, fe_recovery_converged_.

When cached alphas are available, FE recovery does not run an extra pass and reports fe_recovery_iterations_ = 0 and fe_recovery_max_delta_ = 0. Otherwise, the recovery uses a store-alphas MAP sweep on the partial residual y - X beta.

Set XHDFE_FE_DIAG_FILE to append per-run FE diagnostics (partial residual stats, FE totals, residual consistency) to a text file.

FE recovery is not supported when both group and individual are specified; group-only fits use the collapsed sample.

extract_group_individual_fes

extract_group_individual_fes(y, X, fes, group, individual, weights=None, aggregation="mean", ...)

Computes group/individual FE effects using the most recent fit() coefficients.

Arguments:

  • fes: 1-D array, 2-D array (n x k), or a sequence of 1-D arrays (each length n).
  • group, individual: 1-D arrays (length n).
  • weights: optional 1-D array (length n); must sum to a positive value.
  • aggregation: "mean" (default; aliases "avg"/"average") or "sum".

Requirements:

  • fit() must be called first.
  • individual must also appear in fes.
  • At most 3 standard FE dimensions are supported (Stata extractfes limit).

Options (defaults match the C++ GroupIndividualFeOptions):

  • tol_main (1e-9): convergence threshold for the outer loop.
  • tol_start (1e-3), tol_final (1e-9): starting/final tolerances for the inner solver.
  • max_iter_main (10000): max outer iterations.
  • max_iter_solver (1000): max inner iterations.
  • verbose (0): 0 = silent; higher values emit progress.
  • accel (2): acceleration mode (0 none, 1 linear, 2 geometric).
  • start_accel (5), every_accel (5): acceleration schedule.
  • factor (1.0): tighten solver tolerance if MSE < factor * tol.
  • a1p1 (0.75): linear acceleration parameter.
  • a2p1 (1e-8), a2p2 (5): geometric acceleration parameters.

Return dict:

  • individual_ids, individual_effects
  • fe_level_ids, fe_level_effects
  • iterations, converged, mse

Minimal usage example

import py_hdfe_v11 as hdfe

reg = hdfe.HdfeRegressor(se_type="robust", tol=1e-8, max_iter=5000, num_threads=8)
reg.fit(y, X, fes=[firm_id, year_id], weights=weights)
print(reg.summary())

Grouped example:

reg = hdfe.HdfeRegressor(se_type="cluster", tol=1e-8, max_iter=5000)
reg.fit(y, X, fes=[inventor_id], group=patent_id, individual=inventor_id, aggregation="sum")
